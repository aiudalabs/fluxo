## Qué es Fluxo

**Fluxo** es una **fábrica de software gobernada**, vendida por **AIuda Labs**. Toma el brief de un
cliente (en español), lo convierte en un **backlog gateado y trazable**, y ejecuta el trabajo con
**agentes de IA** corriendo en el GitHub del propio cliente. Todo el conocimiento operativo queda en un
registro auditable.

La tesis de arquitectura: **alquilar el sustrato determinista** (Postgres + RLS, GitHub Actions) como
configuración declarativa, y dejar como código propio **solo el método** — que vive como *data*
(YAML + markdown) en el `registry/`, nunca hardcodeado.

## Los dos planos

Todo lo que hace Fluxo cae en uno de dos planos:

- **🧠 Diseño / planeo** — corre en el *worker* (con el Claude Agent SDK). Convierte ideas en backlog y
  gestiona las ceremonias Scrum. Los agentes de este plano son *analistas, PMs, arquitectos, diseñadores*.
- **🔨 Build** — corre en las **GitHub Actions del cliente** (con SU token → cero costo de infra para
  Fluxo). Los agentes de este plano son *desarrolladores* que escriben el código de cada story.

El detalle completo está en [Workflows y agentes](/metodo/workflows-y-agentes/).
